# Full-Stack-Blog-Platform
A full-stack blog platform where users can register, log in, create, view, update, and delete blog posts using React, Node.js, Express, and MongoDB.
## run
1. Install Node.js and MongoDB.
2. `cd server && npm install`
3. Copy `.env.example` to `.env` and set values.
4. `npm run dev`
5. In another terminal: `cd client && npm install && npm run dev`
6. Open the Vite URL shown in the terminal.
